# Weather_Dashboard Page


A clean, responsive, and user-friendly weather application designed to quickly fetch and display real-time weather details for any city.

---

## ✨ Features

- **City Search:** Easily look up current weather conditions by typing any city name into the input field.
- **Instant Results:** Click the **Get Weather** button to fetch up-to-date data.
- **Clean & Modern UI:** Features a sleek, card-based interface with a vibrant blue background theme.
- **Responsive Layout:** Optimized to look great across different screen sizes.

---

## 🛠️ Technologies Used

- **HTML5** – For structure and layout
- **CSS3** – For styling, card components, and color themes
- **JavaScript** – For handling user input and API data fetching *(Update if using a specific weather API)*
